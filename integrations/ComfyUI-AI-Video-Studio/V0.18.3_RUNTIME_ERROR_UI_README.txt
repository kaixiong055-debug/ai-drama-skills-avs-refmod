AI Video Studio v0.18.3｜运行错误直接显示版

本版重点：不再要求用户去 ComfyUI 黑色日志窗口寻找 AVS 报错。

1. 后端运行异常会通过 avs_runtime_error 事件直接回传导演工作台。
2. 工作台顶部显示持久红色错误卡片：
   - 当前操作（如“二采当前视频段失败”）
   - 中文错误原因
   - 修复建议
   - 当前视频段和异常类型
3. “当前视频段还没有一采完成的视频”会提供【生成当前一采】按钮。
4. 二采按钮提交前再次检查当前段是否有一采/正式版源视频，缺失时前端直接拦截，不提交 ComfyUI 任务。
5. 切换到没有一采结果的视频段时，如果隐藏 generation_scope 仍残留“二采当前视频段”，自动重置为“当前视频段”，避免用户点击 ComfyUI 顶部运行按钮时误触发旧二采动作。
6. Turbo LoRA / REF2VA 类型不匹配、模型连接缺失、Picture 缺失、CUDA OOM 等运行中错误也会直接显示在 Studio。
7. ComfyUI 原始 Traceback 仍保留，便于高级排查，但日常使用无需再翻日志。

建议测试：
- 找一个尚未生成一采的视频段，尝试二采，应在 Studio 内直接出现“请先生成当前一采”的红色错误卡片。
- 故意给 REF2VA 配置 FL2V Turbo，运行后 Studio 应直接显示 Turbo LoRA 类型不匹配提示。
