AI Video Studio v0.18.6｜全局造型库（基于 v0.18.5 最小增量）

本版只增加“全局造型库”，不改现有 RefMod / Skills / 一采 / 二采 / 人物绑定逻辑。

【现有逻辑保持不变】
- 人物身份：Identity RefMod
- 人物造型：Clothing RefMod
- 分镜里选择人物 + 造型后，仍按原来的 bind_shot 流程注入。

【新增】
1. 人物库顶部新增【全局造型库】。
2. 某人物已有造型可点击【保存到全局库】；只需要保存一次。
3. 任意人物可点击【从全局造型库绑定】，不再逐张选择图片。
4. 已从全局库绑定的造型显示【全局库】标记。
5. 更新同一套全局造型后，可以重新绑定/同步到人物，再重新准备 RefMod。

【跨项目】
全局造型库不保存到单个导演项目，因此任何项目都可重新绑定。

【跨电脑】
全局库的 library.json 和原始造型图片都存放在你选择的全局造型库目录中，而不是只保存在 ComfyUI 的人物库数据库里。
推荐把目录设置到：OneDrive / Dropbox / NAS / 共享盘 / 可同步移动盘。
换电脑后：安装同一版插件 -> 打开人物库 -> 全局造型库 -> 选择同一个同步目录，即可直接看到原有造型并绑定。

注意：插件不会自动把本地硬盘文件上传到互联网。要真正跨电脑自动同步，目录本身需要由 OneDrive/Dropbox/NAS 等负责同步。
