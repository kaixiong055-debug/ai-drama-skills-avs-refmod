# 导演工作台：人物库与直接选图

更新后先保存当前工作流，重启 ComfyUI 后端，再刷新页面。

在工作流列表打开「AI_Video_Studio_人物库直用版」，或继续使用现有导演工作台。

## 设置人物

1. 点击导演工作台的「人物库 / 本剧演员」，新建人物并填写姓名。
2. 上传你已有的一张清晰正脸。侧面等角度可选，最多四张身份参考。
3. 在「服装与造型」中添加西装、居家服等造型。四视图可以直接作为一张造型参考上传；不会自动拆成四张。
4. 将人物加入本剧，设置为男主、女主、配角或其他。
5. 参考精度先使用 512，选择 H3 视频 VAE，点击「保存并准备人物参考」。等待 ComfyUI 队列完成。

准备过程使用本机 VAE 编码你上传的图片并保存 RefMod，不生成新的人物图片，也不是训练人物 LoRA。图片没有变化时会复用结果；只修改造型图时，已准备的身份参考继续复用。

需要清理历史版本时，点击「删除旧参考并重新生成」。它会先保存当前资料并排队，任务开始执行时删除该人物目录中由人物库生成的旧身份及造型 RefMod，再重新准备当前参考。上传图片、其他人物及手动放入的其他文件不受影响。若重新准备失败，旧参考已删除，需要再次准备。普通「保存并准备人物参考」仍会复用未变化的结果。

## 每段怎么使用

在「本段出场人物」选择演员，点击「加入本段」，再选择该段使用的造型。人物占一个 Picture 槽位，默认选择空槽位；需要替换旧人物图时，可手动指定对应槽位。请同时保持提示词中的 Picture 编号、人物及服装描述一致。

身份和造型参考分别保存，生成时只加载本段实际选择的人物和造型。未准备、图片已改动、造型被移除或参考量超出预算时，会明确提示处理，不会悄悄跳过。

首次建议每人一张正脸、一张造型图，先验证一个短镜头。多人物、多角度和高精度会增加显存与参考量；超过预算时减少角度或降低参考精度后重新准备。该功能用于 REF2VA 多素材参考模式，提示词需要包含 subject_definitions。它能提供身份参考，但不能保证每个镜头都完全不变脸，效果仍需生成视频确认。

## 选图与旧工作流

点击空 Picture 卡片的「选择图片」或已有图片的「换」，直接打开电脑文件选择窗口。场景和道具照常选取，不经过素材中心。

新模板没有「永久资源库」节点和外接人物 RefMod 配置链。旧工作流中没有使用资源库素材时，导演工作台会移除多余资源库连接；若仍有旧资源编号引用，则保留连接以免素材丢失。选好的本地文件会上传到 ComfyUI 输入目录。

人物数据由插件内部维护；不需要手动编辑或管理人物 JSON 文件。旧人物 RefMod 配置节点仍保留兼容，新的本段人物选择优先生效。
