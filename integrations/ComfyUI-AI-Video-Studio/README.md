# AI视频工作室 v0.18.2 V2.6




## v0.18.2｜近景稳定人脸修复

- 人脸修复新增：`近景稳定`、`中远景重建`。
- `自动`仍然保护清晰近景；如果近景也想补细节，选择`近景稳定`。
- 近景稳定默认：768脸部处理、实际 denoise 约 0.06、低融合 0.30。
- 同一次修脸任务整段固定同一个 Seed。
- H3 分窗改为 22 帧连续上下文：上一窗最后22帧进入下一窗，不再独立切换人脸。
- 人脸裁剪框、五点对齐变换均做时序平滑，减少眼睛/鼻子/嘴的像素级抖动。
- 已绑定人物 RefMod 时，近景修复自动限制到不高于 0.25，避免身份过强导致脸型漂移。
- 启用人脸修复时自动保留一采 RAW latent；做二采时优先从 RAW latent 恢复源画面，避免“一采修一次、二采再修一次”。

## v0.18.1｜剪映式时间轴局部重绘

本版新增导演工作台内的连续时间轴编辑器。视频不需要全部生成完：从第一段开始，只要前面的正式片段连续已有结果，就可以直接在时间轴上用鼠标拖选任意范围进行局部修改。选择范围可以跨原始视频段，例如 S02/S03 交界处的 9.20s–11.70s 会作为一个连续区域一次重绘，不拆成两次生成。

- 拖拽选区：时间轴按实际已生成视频时长读取元数据，显示连续可编辑范围。
- 跨段重绘：不受每段 5 秒边界限制；自动抽取选区前后上下文窗口。
- 三种模式：`局部修补`、`动作重绘`、`剧情重生成`。
- H3 原生时序重绘：源窗口编码为 H3 AV latent，只把选中的时间 token 设为可重采样，前后上下文保持锁定。
- 双边界锚定：选区前后自动加入 H3 guide，降低动作/人物/镜头在接缝处跳变。
- 声音默认锁定：局部重绘不改原时间线声音，最终成片继续使用原音轨。
- 非破坏补丁：每次局部生成保存为独立 patch；可在时间轴下方单独撤销/恢复，不覆盖原视频段。
- 最终合成自动应用所有启用的 patch；重叠 patch 按创建顺序应用，后生成的修改覆盖重叠部分。
- 支持生成途中修改：例如只生成到第三段时，可以立即改 9–11 秒，确认后再继续生成后续段。

> 需要较新的 ComfyUI（支持 MiniMax H3 AddGuide、Nested AV latent 与 temporal denoise mask）。建议更新 ComfyUI 后再使用本功能。

## v0.17.1｜主界面移除“面部清晰提示”

- 一采 H3 模型节点不再显示“面部清晰提示”。
- 该旧功能仅是向提示词追加清晰面部描述，不属于真正的人脸修复；现已默认永久关闭。
- 人脸相关主流程只保留“人脸修复：关闭 / 自动 / 强制”，避免与自动局部修复逻辑重复。
- 内置示例工作流同步移除旧控件值，防止加载旧示例时字段错位。

## v0.17.0｜一采统一人脸修复策略 + 自动远景判断

- 一采 H3 模型配置新增唯一的人脸修复入口：`关闭 / 自动 / 强制`，默认 `自动`。
- `自动`不看提示词写了什么景别，而是检查生成后视频中的实际人脸大小和清晰度：近景清晰脸直接跳过，中远景/远景小脸才进入 H3 局部修复。
- 人脸检测由最长边 640 提升到 1280，并增加裁剪框中心+尺寸时序稳定，提升远距离小脸的可检测性和运动画面稳定性。
- 二采高清设置移除重复的“人脸增强/仅增强人脸/脸部尺寸/融合强度/时序稳定”等主界面参数；二采只负责高清/精修。
- 新增独立 `二采可选模型` 节点类型，不再在二采模型节点重复显示一采的人脸修复开关。
- 当用户随后执行二采时，会在二采完成后再次按一采的人脸修复策略检查最终视频，无需重复配置。
- 自动模式遇到多人镜头、没有唯一参考头像、没有需要修的连续小脸时会安全跳过，不会为了“开了修复”而硬改近景脸。

推荐日常设置：`人脸修复 = 自动`。只有明确完全不需要修脸的片段才选 `关闭`；测试或明确需要重建时再选 `强制`。


## v0.16.9｜隐藏空间预热 → 22帧续写正式近景

这一版专门解决 H3 在 2～5 人多轮对白中“切近景后人物换边、漂移、越轴”的问题。新增一种**生产专用卡片：隐藏空间预热（LOCK）**。

正确流程：

```text
LOCK_SCENE（约1秒 / 22帧 / 群像定位 / 不进成片）
        ↓ AddGuide 取尾部22帧
SEG001（正式5秒，可直接从近景开始）
        ↓ AddGuide
SEG002（正式5秒）
        ↓
SEG003……
```

- 导演工作台顶部新增【+ 空间预热】。它会在当前正式视频段前插入一个隐藏 LOCK 卡片，并复制当前段的 Picture 绑定、集数和场景。
- LOCK 默认约 1.0 秒、单张生成、独立生成、无尾音继承；提示词只要求所有对话人物同框并保持轻微待机，建立左/右、前/后、距离、朝向、视线与 180° 轴线。
- LOCK 会像普通 H3 片段一样真正生成，因此下一张正式卡片可直接使用现有 AddGuide 逻辑读取它的尾部 22 帧。
- 正式段紧跟同场景 LOCK 时，后端自动把它视为“续写上一段”，即使它是该场景第一个正式镜头。
- **LOCK 永远不进入最终成片**；【合成最终视频】会自动跳过全部隐藏预热卡片。
- 正式段仍按自己的目标时长交付。因为最终合成会裁掉 AddGuide 重叠窗口，后端对“LOCK → 第一正式段”自动增加约 22/24 秒的生成预算，裁完后仍接近用户要求的 5 秒。
- 同一场景后续正式段继续从上一正式段续写，不需要每段重复 LOCK。仅在新场景、角色进退场、明显换位、换轴或实测漂移时再加新的 LOCK。
- 隐藏预热不需要二采；工作台会阻止对 LOCK 执行二采。
- 项目统计现在区分“正式段”和“空间预热段”，成片目标时长只计算正式段。
- 批量 MD 支持 V4.4 元数据：`【段类型】`、`【成片】`、`【空间锁ID】`、`【空间锁来源】`，并支持 `【空间预热 LOCK_xxx｜1秒｜名称】` 卡片头。

### 手动使用

1. 选择某场戏的第一张正式视频卡片。
2. 点击【+ 空间预热】。
3. 编辑 LOCK 提示词，把 2～5 人的真实左/右、前/后、朝向、视线、关键家具写清楚；不要放关键对白或复杂动作。
4. 先生成 LOCK；也可以直接点正式段的【生成当前一采】，系统会自动补齐缺失的前置续写链。
5. 正式段可直接从说话人的近景开始。
6. 最后点击【合成最终视频】，LOCK 自动排除。

- H3 AddGuide 续写仍完整保留上一段尾部 22 帧作为生成引导，不改变生成质量与连续性。

- 最终状态会显示“续写去重 X 段 / Y 帧”。

## v0.16.5｜素材包一键导入 + V2 批量制作协议


### v0.16.5 新增｜一键导入整个图片素材包

导演台现在支持两种不需要逐张找图的方式：

1. **推荐：批量导入提示词时，同时选择整个图片素材文件夹**
   - 选择 `H3批量导入.md`
   - 可选选择 `asset_manifest.json`
   - 点击“选择图片素材文件夹”，一次选择整套 PNG/JPG/WebP
   - 点击“创建视频段”后，系统按 `【Picture绑定】P1=...` 与图片文件名/manifest 精确匹配，自动上传并绑定到所有视频段。

2. **提示词已经导入后：点击导演台顶部“一键导入素材包”**
   - 只需要选择一次整个素材文件夹
   - 系统会读取每个视频段保存的 `Picture绑定` 标签，自动把图片批量导入 `ComfyUI/input/AI_Video_Studio/local_media` 并填入 Picture 1–9。

素材文件名应使用 canonical asset ID，例如：
```text
CHAR_SHENYAN_RAIN.png
SC_GATE_RAIN.png
PROP_HORSE.png
```
也支持 `asset_manifest.json` 的 `output_filename` / `aliases`。只做唯一精确匹配，不会用模糊匹配把 MASTER、H3主参考或服装 Variant 绑错。

> 注意：旧版已经创建的视频段没有保存 `Picture绑定` 标签。升级后请重新执行一次“批量导入提示词”，之后即可永久使用“一键导入素材包”。

- 批量导入器支持 V2 元数据：`【H3模式】`、`【Speaker绑定】`、`【Picture绑定】`。
- Picture 自动绑定改为**严格唯一精确匹配**：canonical 名称 / manifest output filename / manifest alias；不再用模糊 containment 自动确认，防止 `MASTER / H3主参考 / FACE / 服装Variant` 串绑。
- 可在批量导入窗口同时载入 `asset_manifest.json`，用于 output filename 和 alias 解析。
- 模糊结果只作为候选提示，不会写入 Picture 槽。
- 导入前增加 Picture“已绑定但 Prompt 未引用 / Prompt 引用未绑定”等协议检查。
- 解析器同时识别 H3 Ref2VA 六段式与 base 三段式文本；**当前 AVS 的实际 H3 模型执行模式仍由项目级 H3 模型配置决定**，普通批量漫剧继续推荐 REF2VA。
- 不改变现有 AddGuide 22帧续写、尾音继承、抽卡、二采和最终合成功能。

## v0.15.7 变更

- 删除 `AI视频工作室｜显卡自动设置` 节点。
- 删除 H3模型配置、二采高清设置、导演工作台上的 `显卡自动设置` 输入端口。
- 一采 Steps / CFG / 采样器 / 调度器 / 降噪不再被外部显卡配置覆盖。
- 二采仍保留自身的“显存自动保护”开关，可由用户自行决定是否启用。
- 抽卡、Picture 真引用、续写、二采、A/B 对比、最终合成功能保持不变。


## v0.16.8 - 额外参考视频直接上传

- 导演台“额外参考视频”新增 **＋选择/上传视频** 按钮。
- 支持直接选择 MP4 / MOV / MKV / WEBM 等本地视频。
- 上传文件自动复制到 `ComfyUI/input/AI_Video_Studio/local_media/`。
- 每个视频段最多绑定 3 条本地参考视频。
- 本地参考视频无需先进入永久素材库，也无需手写 `@` 引用，会直接作为 MiniMax H3 `ref_video_0..2` 发送。
- 旧版“@动作视频/某段视频”入口继续保留，旧项目兼容。
- 界面显示视频预览，可直接播放、删除并重新上传。


## v0.18.3 运行错误直接显示

- AVS 后端异常直接回传导演工作台，以红色错误卡片显示。
- 可提前判断的二采/模型/素材问题在提交前拦截。
- “没有一采却点二采”可一键跳转生成当前一采。
- 保留完整 ComfyUI Traceback 供高级排查。

## v0.18.4 双配置节点 + H3潜空间×2二采

- 新增 `AI视频工作室｜二采 H3潜空间高清`，一个节点同时输出二采模型配置和二采高清设置。
- 推荐生产链：480P 一采（保存 RAW latent）→ H3 latent ×2 → 4步、denoise 0.12 二采 → 约960P。
- 新工作流不再需要同时摆放“二采可选模型”与“二采高清设置”，配置节点从三个简化为两个。
- 默认关闭一采局部人脸修复，避免同一段视频额外消耗数分钟。
